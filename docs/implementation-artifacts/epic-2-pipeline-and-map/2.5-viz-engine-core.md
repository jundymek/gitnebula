## Story

As a developer opening the map,
I want the nebula to render, settle and respond at the mockup's exact look,
So that the first view already delivers the wow.

## Context (binding)

- PRD FR-6 (refusal screen), FR-12, FR-13, FR-15; AD-5 (GraphEngine =
  layout+render behind ONE interface; chrome talks only to it), AD-6
  (seeded PRNG from `hash(repo.name)`; Settled = max displacement
  < 0.5 px/frame × 30 frames — one exported constant), AD-12 (fetch
  `./analysis.json`, version check HERE), ADR-0006, UX-DR1–6, 9–11.
- `reference/mockup.html` is your behavioural reference: palette custom
  properties, glow gradients, star seeding, curve midpoint math, header
  layout. Its O(n²) simulation and unfold-everything are the two things you
  must NOT copy (spike report at `docs/dev/epic-1/1.4-perf-spike/` tells
  you what to do instead — read it first, its verdict binds you).
- Vanilla TS. No UI framework. d3-force is your only runtime dependency.

## Acceptance Criteria

- AC-1: Vite dev serves a chosen contract fixture at `./analysis.json`
  (mechanism documented); the viewer fetches only that URL; a fixture with
  major version ≠ `SUPPORTED_SCHEMA_MAJOR` renders a clear error screen
  naming both versions (FR-6).
- AC-2: On load, nodes appear and visibly settle; Settled reached in 2–3 s
  on the 100-module fixture (automated: displacement-based, from first
  render); camera then fits the graph ≤ 800 ms; a replay control re-runs
  it; layout is identical across reloads (seeded); `prefers-reduced-motion`
  renders pre-settled (FR-12, AD-6).
- AC-3: Encoding matches the mockup exactly: palette hexes (#3fcfa0/
  #9b8cff/#7c8598/#a8cf52/#ff7a3d on #060911), node radius ∝ √LOC, glow
  radial gradient ∝ churn, hot nodes (churn ≥ configured threshold, default
  0.5) render `--hot` REPLACING layer colour and pulse ~380 ms (still under
  reduced-motion), starfield ~220 stars two sizes, module labels above
  nodes, curved translucent edges (FR-13, UX-DR1–5).
- AC-4: Chrome: header (brand, repo name, stats bar with name/files/LOC/
  modules/commits/languages), legend (4 layers + hot spot), bottom-right
  hint overlay — all per mockup layout; module count derived from nodes
  (FR-13, UX-DR6/9).
- AC-5: Drag pans; scroll zooms cursor-centred, clamped [0.4, 6.0]; grab/
  grabbing cursors (FR-15, UX-DR10).
- AC-6: Structural rule holds: chrome modules import the GraphEngine
  interface only — no canvas/context/simulation access outside the engine
  implementation (enforced by directory structure + a lint boundary or a
  test that greps imports; document which).
- AC-7: The GraphEngine interface (load/seed/events/camera/pick/mode/
  highlight/exportPNG) is defined in full even where this story implements
  only part — 3.3/3.4/3.5 build against it unchanged (their specs are
  frozen against your interface; changing it later = coordination cost you
  personally caused).
