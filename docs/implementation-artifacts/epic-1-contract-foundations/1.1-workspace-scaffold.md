## Acceptance Criteria

- AC-1: On a fresh clone (Node ≥ 20, pnpm 10), `pnpm install && pnpm lint &&
  pnpm test` all exit 0; `pnpm test` executes at least one (trivial) vitest
  suite in each of the six packages.
- AC-2: Workspace contains `@gitnebula/{contract,scanner,deps,githist,viz,cli}`,
  each with `"type": "module"`, an `exports` map (deep imports like
  `@gitnebula/contract/src/x` do not resolve), and only the AD-2 dependency
  edges declared in `package.json` (cli → all four Node packages + contract;
  scanner/deps/githist/viz → contract only).
- AC-3: ESLint 9 (flat config) + Prettier are root-configured; a file inside
  scanner/deps/githist calling `Date.now()` or `Math.random()` fails
  `pnpm lint` (AD-4); viz and cli are exempt from that specific ban.
- AC-4: `tsconfig` layout per AD-11: shared base, NodeNext resolution;
  `packages/viz` uses DOM lib and no `node:` types; the other five compile
  Node-side (`contract` additionally must not import `node:` modules —
  environment-neutral).
- AC-5: `.github/workflows/ci.yml` runs `pnpm lint` + `pnpm test` on push and
  PR, and is green on your branch.
- AC-6: MIT `LICENSE` (copyright holder: Łukasz Jundziłł) and `CONTRIBUTING.md`
  exist at the root; CONTRIBUTING covers: Conventional Commits with scope =
  module, the `Refs:`/`Agent:` trailers (also in PR bodies — squash merge),
  squash-merge policy, and how to run lint/tests.
- AC-7: `pnpm build` builds cli (tsup, may emit a placeholder binary) and viz
  (vite, may emit a placeholder page) — the two AD-11 build edges exist and
  run; internal packages have **no** build step.

### Completion Notes List

- All seven ACs verified locally: `pnpm install`, `pnpm lint`,
  `pnpm typecheck`, `pnpm test` (6 suites, 11 tests, all green) and
  `pnpm build` (tsup binary runs; vite emits dist/index.html) exit 0.
- AD-4 ban demonstrated red and green: a temp file calling `Date.now()` /
  `Math.random()` in `packages/scanner` fails `eslint` with two
  `no-restricted-properties` errors; the same file in `packages/cli` passes
  (exempt). Deep import `@gitnebula/contract/src/index.ts` fails with
  `ERR_PACKAGE_PATH_NOT_EXPORTED` (AC-2 negative check).
- Deviation from AD-4's rule name: the ban is implemented with
  `no-restricted-properties` (exactly `Date.now` / `Math.random`), not
  `no-restricted-globals`, which can only ban whole globals and would outlaw
  deterministic `new Date(isoFromGit)` parsing that AD-13 expects. AC-3's
  observable behaviour is matched exactly.
- Addition beyond the AC-5 letter: CI also runs `pnpm typecheck` — vitest
  transpiles without type-checking, so lint+test alone would leave AC-4's
  "compiles" property unverified in CI.
- Shared dev-dep versions (`typescript`, `vitest`, `@types/node`) are pinned
  once via the pnpm catalog in `pnpm-workspace.yaml`.
- Minor pins chosen at first story per architecture: pnpm 10.34.5,
  TS 5.9.3, ESLint 9.39.5, Vite 8.2.1, vitest 4.1.10, tsup 8.5.1,
  prettier 3.9.6, typescript-eslint 8.67.0, @types/node 20.19.43.
- Per-story docs live at `docs/dev/epic-1/1.1-workspace-scaffold/README.md`

  story has no UI/route/interactive surface; rationale recorded in the
