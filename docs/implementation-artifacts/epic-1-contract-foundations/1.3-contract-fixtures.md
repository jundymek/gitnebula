## Story

As an analyzer or viewer developer,
I want committed edge-case `analysis.json` fixtures and deterministic fixture git repos,
So that viz builds against the contract alone and githist tests have known history.

## Context (binding)

- PRD FR-6 (fixture list), AD-14 (fixture repos built, never committed),
  AD-13 (fixture tests pin `windowAnchor`), ADR-0006/PRD FR-14 (the
  synthetic 100-module/2,000-file fixture is the perf yardstick).
- These fixtures are the ONLY thing viz stories see until M2. Edge cases you
  skip here become integration surprises later — err toward nasty.

## Acceptance Criteria

- AC-1: `@gitnebula/contract` ships validating fixtures: empty graph, single
  module, cyclic imports (a→b→c→a at module level), module with zero files,
  zero-history repo (all `churn: 0`), and a synthetic 100-module/2,000-file
  document produced by a committed generator script (output committed too;
  regeneration is byte-identical — seeded).
- AC-2: A `fixtures/README.md` names each fixture's purpose and the edge it
  guards.
- AC-3: `test-fixtures/` contains build scripts that replay crafted commits
  with pinned `GIT_AUTHOR_DATE`/`GIT_COMMITTER_DATE` and fixed identity into
  gitignored `test-fixtures/.generated/`; running twice on any machine gives
  identical commit hashes (AC test does exactly that).
- AC-4: The crafted history covers: a rename (content preserved), a
  multi-file commit (co-change source), a file touched by 3 distinct
  authors, a file whose only commits predate the analysis window, and a
  Python + TS file mix.
- AC-5: The build scripts run automatically before tests (root pretest) and
  in CI; a fresh clone's `pnpm test` passes with no manual step.
