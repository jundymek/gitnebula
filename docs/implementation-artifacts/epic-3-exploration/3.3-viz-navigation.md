## Story

As a developer exploring the map,
I want zoom to unfold modules, hover to reveal dependency chains, and search to fly me anywhere,
So that a 2,000-file repo is navigable in seconds.

## Context (binding)

- PRD FR-16, FR-17, FR-18; ADR-0006 (viewport-scoped unfold — spawn members
  at module position, settle locally, global layout undisturbed), AD-5
  (everything through the GraphEngine interface from 2.5 — frozen), AD-6
  (determinism holds through unfold), UX-DR5, 8, 10, 11.
- Mockup constants: UNFOLD_ZOOM 1.8, file labels ≥ 3.0×, chain alphas
  0.62/0.03, dim 0.1, flyTo 620 ms cubic ease-out, targetK 2 (module) /
  3 (file).

## Acceptance Criteria

- AC-1: Crossing 1.8× unfolds ONLY modules intersecting the viewport
  (+margin); panning a collapsed module into view at ≥ 1.8× unfolds it;
  dropping below 1.8× collapses all; file labels from 3.0×; member files
  spawn at their module's position and settle locally — automated test
  asserts non-member displacement stays under the Settled bound during an
  unfold (FR-16).
- AC-2: Hover highlights the one-hop chain (chain edges 0.62; a hovered
  module also lights its member files when unfolded); non-chain nodes dim
  to 0.1, edges to 0.03; tooltip `name · churn N%` follows the cursor,
  never overflows the viewport; hover exit restores full opacity (FR-17).
- AC-3: The persistent search box (top-left, `⌘K` kbd hint) focuses via
  Cmd/Ctrl+K and `/`; fuzzy subsequence match over node ids; top 7 results;
  arrows + Enter navigate, Esc closes and blurs; selecting flies the camera
  620 ± 50 ms ease-out to 2.0× (module) / 3.0× (file), pulses the target,
  opens the panel via an engine event (3.4 consumes it); a file inside a
  collapsed module unfolds it on arrival; reduced-motion jumps instantly
  (FR-18, UX-DR8/11).
- AC-4: All interaction flows through the GraphEngine interface + events —
  no new direct canvas access outside the engine (the 2.5 boundary check
  still passes).
