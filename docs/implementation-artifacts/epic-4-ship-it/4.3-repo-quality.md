### Debug Log References

- The recorder's first three runs failed and each failure was a fact worth
  keeping: `#p-close` is a **class**, not an id (`panel.ts` sets `id` only on
  `p-isolate`/`p-github`); the engine's `pick()` speaks canvas-relative
  coordinates while Playwright's mouse speaks viewport ones, and the header
  offsets the canvas by 55 px — clicking without that offset silently selects
  nothing; and hovering wakes the layout, so a node drifts between the scan
  that finds it and the click that wants it (hence `clickNode`'s re-resolve
  loop).
- GIF encodes measured from one 25 s capture: 900 px/12 fps/128 colours
  dithered = 10.0 MB, 800/10/96 = 6.4 MB, 760/10/64 = 5.1 MB,
  **720/8/64 = 3.7 MiB** (shipped), 640/8/48 = 2.7 MB.
- Codex auto-review raised one P1 (`npx gitnebula` resolves to nothing while
  the packages are private). Addressed in the copy rather than by dropping the
  command — see Completion Notes.
- Codex auto-review also raised one P2 on the re-record recipe: Playwright
  names its recording after the page GUID, so a second run into the same
  `DEMO_OUT` left two files and the recipe's `*.webm` glob then fed ffmpeg a
  stray output argument. Fixed at the source — the script renames its take to
  `DEMO_OUT/demo.webm` and prints that path, and the recipe points at the one
  file. Verified by running the recorder twice into the same directory: one
  `demo.webm`, replaced.

### Completion Notes List

- The repository had **no README at all**; this story creates it. Order is
  AC-1's: pitch → demo → quickstart → map-of-itself → features → CI badge →
  licence.
- **The demo is a real recording of this build**, not a placeholder:
  gitnebula analyzing its own checkout, driven through the full scripted
  sequence. Recorded with Playwright (`recordVideo`) via
  `scripts/record-demo.mjs`, encoded with ffmpeg.
- **Deviation from the spec's wording, deliberate:** the spec says "external
  recorder". Playwright *is* external to the product — already a `viz`
  devDependency for the perf harness, nothing entering the bundle — and it is
  what makes AC-3's "reproducible" true: a desktop screen recording cannot be
  re-run identically, a script can. Node positions resolve at runtime through
  the engine's public `pick()`, so the script survives layout changes.
- **AC-4 partially executed, honestly.** The repo is private and this agent's
  browser is not signed in, so the branch page answers 404 to it. The render
  was verified through GitHub's own renderer (`/readme` with
  `Accept: application/vnd.github.html` at `ref=story/4.3-repo-quality`):
  the demo comes back as `data-animated-image`, the badge `<img>` is present,
  and every relative link (`CONTRIBUTING.md`, `LICENSE`,
  `docs/recording-demo.md`, `docs/assets/demo.gif`) resolves on the branch via
  the contents API. The badge and workflow URLs 404 only to an unauthenticated
  client, because the repository is private. Seeing the page painted in a
  signed-in browser is step 9 of `MANUAL_TESTING.md`, left for the owner.
- **The CI badge does not claim green.** `ci.yml` is `workflow_dispatch`-only
  (its own header defers to story 4.2), so the README shows the badge and one
  factual line about what CI runs, and asserts no status.
- **No vapor claims:** `gitnebula build` (4.1) and the Pages publish (4.2) are
  not on this base and are not advertised. The map-of-itself link is the ONE
  placeholder, with a TODO naming 4.2 — as the spec permits. Follow-ups for
  whoever merges 4.1/4.2 are listed in the per-story README.
- Codex's P1 was **addressed, not dismissed**: the quickstart stays
  `npx gitnebula` (AC-1 mandates it, and it is FR-1's promise), and a line now
  points pre-release readers at the clone-and-build path. Publishing the
  package is AD-11/story 4.1 plus the maintainer's release click.
- `eslint.config.js` gained a globals block for `scripts/**/*.mjs`, mirroring
  the one that already exists for `packages/*/scripts/**/*.mjs`; the recorder
  additionally needs DOM globals because `page.evaluate` callbacks run in the
  browser.
- `pnpm -r test`: **67 test files, 874 tests passed, 2 skipped** (1 file
  skipped). `pnpm lint` clean. No product code was touched.
- AC-5 and the owner steps in `MANUAL_TESTING.md` are left unticked, by
  instruction.
