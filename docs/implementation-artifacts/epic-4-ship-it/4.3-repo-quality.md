## Story

As a visitor deciding whether to try gitnebula,
I want a README that shows the product in 30 seconds,
So that the repo itself sells the tool.

## Context (binding)

- PRD FR-25, SM-7; brief §2 (repo quality is a product requirement) and
  §5.7 (meta-trick: the README contains a live map of itself); GIF
  recording via external tooling (in-tool recording is a non-goal).
- The demo asset requirement is real: **a committed GIF/video showing the
  actual product** — record it from the merged epic branch build. A
  placeholder image fails AC-1.

## Acceptance Criteria

- AC-1: README contains, in order tuned for a first-time visitor: one-line
  pitch, the 30-second demo GIF/video (committed asset or repo-hosted
  media, actually recorded from this build), `npx gitnebula` quickstart,
  the live map-of-itself link (4.2's Pages URL), feature bullets grounded
  in the PRD (no vapor claims), CI badge, license line.
- AC-2: `CONTRIBUTING.md` is complete: workspace setup, lint/test/build
  commands, Conventional Commits with scope = module, `Refs:`/`Agent:`
  trailers incl. PR-body requirement, squash-merge policy, fixture-repo
  regeneration note.
- AC-3: `docs/recording-demo.md` documents how the GIF was recorded
  (tool, resolution, the scripted interaction sequence) so it is
  reproducible for future versions.
- AC-4: README renders correctly on GitHub (checked via branch view) —
  media plays/animates, links resolve, badge live.
- AC-5: Owner gate: final copy review by the maintainer — **MUST be left
  unticked**.
