## Acceptance Criteria

- AC-1: A committed `docs/dod-report.md` records, per demo repo (pinned
  SHA, reference hardware spec): wall-clock `npx gitnebula` time (≤ 60 s),
  crash-free completion, `analysis.json` size (≤ 5 MB), unresolved-import
  rate (≤ 20%), schema validation pass.
- AC-2: The report records the global checks: offline run (network
  disabled) on a local path; bundle zero-external-requests re-check;
  fps harness number on reference hardware; viewer bundle gzip size.
- AC-3: Every failed threshold gets a filed GitHub issue linked from the
  report — the report may not hide red numbers (a red number with an issue
  is a valid story outcome; a hidden one is not).
- AC-4: The human-review checklist is prepared for the maintainer: per-repo
  PNG exports embedded/linked, the checklist copied into the report with
  evidence links prefilled — **the checklist walk itself MUST be left
  unticked** (owner gate; superman reports readiness, the owner signs).
- AC-5: `sprint-status.yaml` rows for Epic 4 flipped by their owners; the
  report ends with the M3 go/no-go summary for the epic→master merge.

### Debug Log References

- The built CLI could not run against a Python demo repo out of the worktree,
  before 4.1 (`ENOENT … packages/assets/tree-sitter-python.wasm`) or after it
  (`ENOENT … packages/cli/assets/tree-sitter-python.wasm`): a development
  checkout never runs `prepack`, which is what puts the grammar in place. The
  first measuring pass worked around it with a hand-copied `.wasm`; the final
  numbers were retaken through `npm pack` → `npm install <tarball>` in an empty
  directory, which is the path a user actually gets. The two agree within
  0.1 s. The hand-copied directory was removed before committing — it also
  breaks `fixture-build.test.ts`, which walks every directory under `packages/`
  expecting a manifest.
- The network sandbox was verified in both directions before any offline claim
  was made: inside `sandbox-exec … (deny network*)`, `curl https://github.com`
  fails with `Could not resolve host` (exit 6) and `git ls-remote` cannot reach
  GitHub; outside it both succeed.
- PNG exports were produced through the Viewer's own `exportPNG` via a
  throwaway Playwright spec. It was deleted rather than committed (it would
  fail everyone's `pnpm --filter viz perf` run without its env var) and is
  reproduced verbatim in the story README so the images can be regenerated.

### Completion Notes List

- **Dependency redirected on the maintainer's instruction.** The spec makes this
  story depend on `4.2-ci-pages-recipe`; 4.2 was deliberately not launched
  (GitHub Actions billing disabled) and the marker was set to
  `alice:done` (`4.1-build-bundle`) instead. Consequences recorded rather than

  this run, brief §10 DoD item 6 is therefore partial, and `ci.yml` was not
  touched — it stays `workflow_dispatch`-only.
- **No threshold is red**, so no GitHub issues were filed: AC-3's obligation is
  conditional on a failure. All 15 per-repo cells and every global check that
  could be executed on this base pass, the tightest margin being the frame-rate
  floor at 1.07× (and that 59 is a 60 Hz vsync ceiling, not a renderer limit).
- **Every AC-2 line is measured**, because stories 4.1 (PR #37) and 4.3 (PR #36)
  merged into the base while this story was running and the branch was rebased
  onto each: bundle 57.6 kB gzipped of a 2 MB budget, `bundle-check` 4 passed
  (the page requests exactly `/` and `/analysis.json`), the cold-install pack
  e2e green, and the per-repo timings retaken through the installed tarball.
  An earlier revision of the report recorded the first two as *unverified*; the
  history shows both states, which is the intended behaviour of a report that
  refuses to count intent as measurement.
- **The human-review checklist is prefilled and unticked**, in the report and in
  `docs/planning-artifacts/human-review-checklist.md`, which was not modified.
  Where a line has an automated counterpart its number is quoted next to it, so
  the owner's walk is a judgement call rather than a re-measurement.
- **Unresolved-import rate uses the denominator stories 2.2 and 3.1 set**
  (unresolved ÷ edge-capable specifiers, externals excluded); both readings are
  printed. streamlit's 247 unresolved reproduce story 3.1's count exactly on a
  newer SHA, which is a useful cross-check on the pipeline's stability.
- **Only this story's `sprint-status.yaml` row was flipped, and to `review`.**
  In this repository `done` means merged and is written at epic closure by the
  supervisor; an earlier revision of this branch wrote `done` at PR time and it
  was corrected. The rebase onto PR #38 kept `4.5-npm-release` and its comment
  block from the base — union, not replacement.
- **`npx gitnebula` is proved as far as the artefact goes and no further.** The
  timings run through the packed tarball; the literal command still resolves to
  nothing, because the package is `private`, named `@gitnebula/cli` and
  versioned 0.0.0. That is story `4.5-npm-release`, specced mid-wave by the
  epic supervisor and still `backlog`; the report's DoD table says so in place
  of an unqualified tick.
- Regression proof on the final rebased tree: `pnpm lint` clean, `pnpm test`
  **899 passed / 2 skipped** across the six packages (cli 140, viz 371,
